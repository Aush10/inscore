## Source collections (many pages from one publisher)

| Collection | Cards supported | Why useful |
|---|---|---|
| IRMI Insurance Glossary (irmi.com/term/...) | 168 | One page per term with industry-standard definitions; the most broadly useful definitions source. |
| IIAT form specimens (ISO and TDI forms) | 91 | Actual policy wording for HO, TDP, CP, CA and other forms. |
| TDI consumer guides, glossaries and agent pages (tdi.texas.gov) | 83 | Official Texas regulator content. |
| Mike Russ prelicensing course text (15 chapters) | 75 | Textbook explanations of concepts. California-based, so not for Texas rules. |
| Cornell LII Wex (law.cornell.edu) | 66 | Legal terms: tort, negligence, damages, contract law. |
| Texas Insurance Code sections (texas.public.law) | 63 | Controlling Texas law: licensing (ch. 4101/4004), unfair practices (541/542), cancellation (551), auto (1952), guaranty (462). |
| Texas Labor Code (workers' comp) sections | 35 | Controlling Texas WC law (AWW, waiting period, beneficiaries, LIBs/SIBs). |

Note: texas.public.law mirrors the official statutes.capitol.texas.gov text. That site is a JavaScript app, so its text could not be read for citation checks.
